# Industrial-Procedure-to-Video

[English](README.md) | [简体中文](README_zh.md)

**面向工业级生产视频工作流的原创技能。**

Industrial-Procedure-to-Video 将现场图片素材和用户提供的操作说明整理成可追溯的使用手册，并进一步制作逐步骤的操作演示视频。它适用于设备操作、装配、维护和标准作业培训。整个流程不绑定特定的视频平台，节点创建、素材连线和视频生成均以当前画布实际支持的能力为准。

## 工作流程

1. 检查所有图片素材，并为每个图片节点设置唯一、准确的名称。
2. 在 String 或文本节点中创建可编辑的使用手册，包含图片索引和连续编号的操作步骤。
3. 等待用户确认使用手册。每个编号步骤严格对应一个视频分镜。
4. 生成视频前，通过 Lumina 原生交互式选择弹窗询问是否需要旁白。需要旁白时，创建 Audio Generation 节点，逐步收集声音偏好，生成 20–30 秒试音并等待确认。
5. 使用已确认的试音作为统一音色参考，为每个分镜生成独立旁白音频。用户不需要旁白时，跳过完整音频分支。
6. 先生成第一个分镜，并等待用户确认画面和操作流程是否准确。
7. 首个分镜确认后再生成其余分镜。每个分镜连接该步骤对应的图片素材和旁白音频。
8. 检查分镜数量、步骤顺序、素材连线、音频映射、时长限制和视频播放状态。全部分镜完成后再次等待用户确认，再进入后续环节。

每个分镜提示词统一采用“视频内容与画面”“操作顺序”和“画面约束”结构。只有用户要求旁白或音效时，才增加与该分镜实际动作相符的“旁白与音效”部分。无法辨认的图片、缺少依据的技术细节和不完整素材会被标记为待确认，不会被当作事实补写。已确认步骤或素材映射发生变化时，需要重新经过相应确认环节。

每个分镜直接创建在具有明确名称的 Lumina `Video Generation` 节点中。完整提示词直接写入视频节点内部的提示词输入框，不创建独立的 Prompt 文本节点。每张关联图片必须同时具备真实画布连线，以及提示词输入框中可解析的 `@` 引用标签。只有当前分镜需要音频时，才连接与该分镜匹配的音频节点。

所有图片在使用前都要检查宽高比。Lumina 接受的范围为 `0.4–2.5`；超出范围时，基于原图进行安全裁剪或扩图，生成合规的 FIT 派生素材，不拉伸画面，也不改变设备、工具或操作关键细节。视频节点只连接并引用通过复检的 FIT 素材。

编写“操作顺序”前，系统会检查使用手册是否已经包含可执行的制作方法。只有特效名称、专业术语或概括性单句时，将强制暂停生成并联网检索适用工具链及具有来源依据的分步实施流程。检索结果需要先补充到使用手册；仍然无法确定的步骤保持暂停状态。

使用 Lumina `dreamina-seedance-2-5` 的 `r2v` 模式时，每次视频请求所连接音频的合计时长控制在 30.0 秒以内，为模型的 30.2 秒限制保留余量。20–30 秒试音只作为音色参考，不直接连接最终分镜视频。

系统会自动跟随用户操作说明所使用的语言，并将其应用于画布中所有可见内容，包括节点名称、使用手册、分镜提示词、确认问题和状态摘要。用户明确指定语言时，以指定语言为准。稳定编号、设备型号、零件编号、标准和不宜翻译的来源标识保持原文。

## 使用方式

将本仓库导入为技能，或者把 `SKILL.md` 和 `agents/openai.yaml` 放入同一个技能目录。在兼容的节点画布中上传图片素材、提供操作说明，然后调用 `canvas-manual-to-video`。

## 发布字段

- **场景标签：** 知识、视觉设计
- **技能名称：** Industrial-Procedure-to-Video
- **一句话介绍：** 将工业图片和操作说明转换为经过确认的使用手册，并为每个步骤生成一个具有真实素材连线的视频分镜。【使用方法】上传图片、描述操作步骤，然后确认使用手册和第一个分镜。【适用场景】设备操作、装配、维护、培训。【输出内容】使用手册和分镜视频。
- **使用说明：** 上传图片并提供操作说明和画面要求。为所有图片节点命名，创建包含图片索引和编号步骤的使用手册，并等待确认。编写每个分镜的操作顺序前，检查是否缺少可执行细节；若只有效果名称、术语或概括性描述，暂停生成并联网检索适用工具和具有来源依据的分步流程，再补充到手册。生成视频前，通过 Lumina 原生交互弹窗询问是否需要旁白。需要时创建 Audio Generation 节点，逐项收集声音偏好，生成 20–30 秒试音并等待确认。使用获确认的试音为每个步骤创建独立旁白节点，不把试音直接连接最终视频。每次 `r2v` 请求连接的音频合计不超过 30.0 秒。不需要旁白时跳过全部配音步骤。确认首个分镜后再生成其余分镜，并在全部完成后等待最终确认。

## 导入兼容性

仓库仅使用受支持的文本文件格式（`.md` 和 `.yaml`），文件及目录使用兼容的 ASCII 名称。仓库不包含 `.skillignore` 文件，`SKILL.md` 保持在导入器规定的 20,000 字符限制以内。
